# Handover Checklist – [TEN_DU_AN]

## Tài liệu

- [ ] Project context đã điền.
- [ ] Requirement được Product Owner duyệt.
- [ ] Formula spec được nghiệp vụ duyệt.
- [ ] Jira mapping được xác nhận.
- [ ] Architecture và deployment đã ghi lại.
- [ ] Runbook xử lý lỗi đã có.

## Source và repository

- [ ] README có hướng dẫn chạy.
- [ ] `.env.example` không chứa secret thật.
- [ ] `.gitignore` có `.env`, log và file tạm.
- [ ] Commit history sạch secret.
- [ ] Branch/release tag đã ghi nhận.

## Vận hành

- [ ] Backend host và domain.
- [ ] Owner credential/secret manager.
- [ ] Jira PAT owner và thời hạn rotate.
- [ ] Database backup owner.
- [ ] Monitoring/alert owner.
- [ ] Người phụ trách hỗ trợ.

## Nghiệm thu nghiệp vụ

- [ ] Điểm đúng với bảng tính mẫu.
- [ ] Team có tiêu chí riêng.
- [ ] Leader có tiêu chí riêng nếu cần.
- [ ] So sánh liên nhóm đúng formula.
- [ ] Task Jira map đúng member.
- [ ] Task không map được hiển thị cảnh báo.
- [ ] Kỳ khóa không sửa được.
- [ ] Audit log đầy đủ.

## Bàn giao cuối

- [ ] Demo cho Admin.
- [ ] Demo cho Leader.
- [ ] Gửi link hệ thống.
- [ ] Gửi repository.
- [ ] Gửi tài liệu.
- [ ] Revoke credential demo.
- [ ] Xác nhận người nhận đã clone và chạy được.
